# Agent Spec: `question-bank-agent`

## Overview
`question-bank-agent` is an ADK 2.0 graph-based `Workflow` agent that creates and maintains a daily Current Event Question Bank in Google Sheets for undergraduate business and finance pop quizzes. On each update run, it searches the internet for the latest, hottest emerging technology headlines relevant to business/finance students, generates happy, upbeat, undergraduate-tailored multiple-choice questions assessing basic awareness (4 answer choices with 1 correct and 3 incorrect), and syncs them into a Google Sheet storing the question, answer choices, explicit correct answer indicator, news source, and UTC date timestamp. A deterministic Python Google Sheets stage strictly enforces the 5-question cap — seeding 5 questions when empty, refreshing all 5 on a standard daily run (or adding 1–5 when requested), and always deleting the oldest question row (by timestamp) whenever adding a new question would exceed 5 rows. Deployment files are skipped (`--deployment-target none --prototype`).

## Language
`python` (`adk_python`, `google-adk >= 2.0.0`)

## Architecture & Sub-Agents
**Chosen Approach (Option 1):** Deterministic ADK 2.0 `Workflow` pipeline separating grounded web research, structured MCQ generation, and deterministic Google Sheets FIFO maintenance.
*(Weighed against Option 2: Conversational Coordinator `Agent` with `AgentTool` + Google Sheets `FunctionTool`s, which relies on LLM multi-step tool discipline; and Option 3: `SequentialAgent` + Critique `LoopAgent`, rejected as over-scoped for basic-awareness daily quizzes.)*

- **`root_agent` (`Workflow`):** Orchestrates the directed graph from `START`.
- **`load_bank_and_intent` (`FunctionNode`):** Parses the user prompt to determine action (`"update"` with `target_count` in `1..5`, defaulting to `5`; `"view"` for read-only inspection; or `"off_topic"` refusal) plus any optional emerging-tech/finance subtopic focus. Connects to the Google Sheet, ensures the header row exists, loads existing rows (up to 5) so research avoids duplicating existing topics, and routes via `Event(route="research" | "view" | "off_topic")`.
- **`headline_researcher` (`LlmAgent` with `tools=[google_search]`):** Uses ADK's built-in `google_search` grounding in isolation (no custom `FunctionTool`s or `output_schema`) to find fresh, high-interest emerging technology headlines with clear business/finance relevance (e.g., AI in fintech/enterprise, semiconductors, cloud/quantum economics, payments, cybersecurity, automation), excluding headlines already in the current Sheet bank.
- **`prepare_quiz_context` (`FunctionNode`):** Extracts grounded text and verified source titles/URLs from `headline_researcher`'s `Content` and `grounding_metadata` chunks, passing structured context forward to `quiz_writer`.
- **`quiz_writer` (`LlmAgent` with `output_schema=QuizBatch`):** Generates exactly `target_count` upbeat, cheerful, undergraduate-friendly multiple-choice questions assessing basic awareness of the grounded headlines. Validated via Pydantic (`QuizQuestion`: `question`, `option_a`, `option_b`, `option_c`, `option_d`, `correct_option: Literal["A", "B", "C", "D"]`, `source`).
- **`sync_question_bank` (`FunctionNode`):** Writes each validated question to Google Sheets one-by-one using strict FIFO logic: whenever the Sheet already has `>= 5` question rows, sorts rows by `Date Timestamp` ascending and deletes the single oldest question row (never deleting Row 1 headers) before appending the new question with an ISO-8601 UTC timestamp. Emits a cheerful user-facing summary with all 4 options, the correct answer indicator, source, timestamp, rotation summary, and Google Sheet link.
- **`format_bank_view` / `decline_off_topic` (`FunctionNode`s):** Handle read-only bank inspection (`"view"`) and friendly redirection for unrelated prompts (`"off_topic"`).

## Example Use Cases
1. **Initial Seed or Daily Full Refresh (Default = 5 Questions)**
   - **Input:** `"Update today's emerging tech pop quiz question bank for my business finance class!"`
   - **Expected Output:** Searches latest emerging-tech business headlines, generates 5 happy undergrad-toned MCQs (4 choices each, 1 marked correct, grounded source, UTC timestamp). If the Sheet was empty, seeds 5 rows; if it already had 5 rows, deletes the oldest row one-by-one as each of the 5 new questions is added so exactly 5 up-to-date questions remain. Prints the 5 questions and Sheet status.
2. **Incremental Update (Single / N New Questions with Oldest Evicted)**
   - **Input:** `"Add 1 new question on the latest AI fintech headline to the question bank."`
   - **Expected Output:** Reads existing 5 Sheet questions to avoid topic overlap, finds a fresh AI fintech headline, generates 1 upbeat 4-choice MCQ, deletes the single oldest question row (earliest `Date Timestamp`) from the Google Sheet, appends the new question as the 5th row, and reports both the evicted oldest question and the newly added question.
3. **Inspect Current Question Bank (Read-Only)**
   - **Input:** `"Show me the 5 questions currently in the question bank."`
   - **Expected Output:** Routes via `"view"`, reads the current Google Sheet rows without deleting or regenerating anything, and formats them neatly with answers, correct choices, sources, and timestamps.
4. **Off-Topic Request**
   - **Input:** `"Write my accounting homework essay on depreciation."`
   - **Expected Output:** Routes via `"off_topic"` and cheerfully explains it specifically manages the emerging-tech business current event pop-quiz question bank.

## Tools Required
1. **`google_search` (ADK Built-in Grounding Tool):** Attached solely to `headline_researcher` to retrieve real, up-to-date emerging tech headlines relevant to business/finance students.
2. **Google Sheets Bank Manager (Python module invoked by `Workflow` `FunctionNode`s):** Uses `gspread` / `google-auth` with ADC or `GOOGLE_APPLICATION_CREDENTIALS` to initialize headers, read current rows, delete the oldest row by `Date Timestamp` whenever `len(rows) >= 5`, and append validated `QuizQuestion` rows. Supports injectable storage / test mode (`QUESTION_BANK_STORAGE=memory` or temp JSON) exclusively for isolated automated tests and offline eval runs when live Google Sheets credentials are not mounted, while defaulting to live Google Sheets (`QUESTION_BANK_STORAGE=sheets`).

## Constraints & Safety Rules
1. **Strict 5-Question Invariant & FIFO Eviction:** The Google Sheet MUST NEVER hold more than 5 question rows (Rows 2–6). Row 1 headers MUST NEVER be deleted or overwritten. Adding any question when 5 already exist MUST first delete the question row with the earliest `Date Timestamp`.
2. **4-Choice / 1-Correct MCQ Validation:** Every question MUST contain 4 distinct non-empty options (`A`–`D`), exactly 1 designated correct option (`A`, `B`, `C`, or `D`), and 3 incorrect distractors assessing basic awareness (no trick graduate-quant math).
3. **Grounded Sources Only (Zero Hallucinated News):** Every question and `Source` field MUST trace back to headlines retrieved via `google_search` in that run; never invent fake news events, fake stock tickers, or fabricated URLs.
4. **Happy Undergraduate Tone & No Financial Advice:** Questions and user responses MUST maintain an upbeat, positive, encouraging tone tailored to undergraduate business students, MUST remain classroom-safe, and MUST NEVER give personalized investment/trading advice.
5. **ADK Grounding Isolation & Model Preservation:** Never combine `google_search` with custom `FunctionTool`s or `output_schema` on the same `LlmAgent`. Preserve the scaffolded default Gemini model unchanged.
6. **Skip Deployment Files:** Scaffold with `--deployment-target none --prototype` — do not generate Terraform, Cloud Run/GKE/Agent Runtime configs, or CI/CD pipelines.
